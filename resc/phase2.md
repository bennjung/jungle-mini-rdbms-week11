Phase 2. B+ 트리 인덱스
이번 단계 과제는 'B+ 트리 인덱스' 구현 입니다.

실제 DBMS 에서 사용하는 디스크 기반 B+ Tree 를 단순화한 메모리 기반 방식 으로 구현합니다.

테이블에 레코드가 추가되면 ID 가 자동으로 부여 되며, 해당 ID 를 B+ 트리에 인덱스로 등록 해 ID 기반 검색 시 B+ 트리 인덱스를 활용할 수 있도록 만듭니다.

대규모 데이터 삽입 후 성능 테스트 를 진행합니다.

최소 1,000,000 개 이상의 레코드 를 Insert 합니다.

ID 기준 SELECT (인덱스 사용) 과 다른 필드 기준 SELECT (선형 탐색) 간의 속도 차이를 비교해 보세요.

Phase 1 에서 구현한 SQL 처리기 를 그대로 사용하여 연동합니다.
